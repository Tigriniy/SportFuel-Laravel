# SportFuel Laravel
Laravel 13, PHP 8.3–8.5, MySQL/MariaDB. Работают регистрация, вход, восстановление пароля, профиль и управление каталогом.

## Локальный запуск на текущем ПК
1. В XAMPP Control Panel запустить MySQL. Apache для этого способа не нужен.
2. Открыть PowerShell в папке проекта.
3. Выполнить команды в PowerShell:

   ```powershell
   $env:PHPRC = (Resolve-Path '..\php83-sportfuel.ini').Path
   $env:APP_URL = 'http://127.0.0.1:8001'
   & 'C:\php83\php.exe' artisan serve --host=127.0.0.1 --port=8001 --no-reload
   ```
4. Открыть http://127.0.0.1:8001/reg-in.html.

База `sportfuel` и миграции уже подготовлены локально. `.env` и ключ не публикуются.

## На другом компьютере
Установить PHP >=8.3 с mbstring, openssl, curl, fileinfo, pdo_mysql и Composer. Выполнить `composer install`, скопировать `.env.example` в `.env`, указать свои параметры БД. Создать пустую БД sportfuel, выполнить `php artisan key:generate`, `php artisan migrate`, `php artisan serve`. Пароли БД и ключи у каждого окружения собственные.

## Проверка регистрации
Все поля обязательны. Логин — только латинские буквы, ФИО — кириллица, каждое до 30 символов; email до 30 символов, телефон — до 11 цифр. Пароль — от 10 до 72 символов: латинские буквы, цифры и спецсимволы. Повтор логина/email и несовпадающие пароли отклоняются. Пароль хранится как хеш bcrypt. Роль назначается сервером: user.

Контроллер: app/Http/Controllers/RegistrationController.php. Модель: app/Models/User.php. Маршруты: routes/web.php. Представление: resources/views/reg-in.blade.php. Таблица: users.

Проверены HTTP-отправка валидной формы, отклонение повторного логина/email (422), неверного логина и несовпадения паролей (422).

## Управление каталогом

- В новом окружении выполнить `php artisan migrate` и `php artisan storage:link` для загружаемых изображений.
- Если нужны восемь демонстрационных товаров из старой вёрстки, один раз выполнить `php artisan db:seed --class=CatalogDemoSeeder`. Начальный остаток каждого товара равен нулю.
- Зарегистрировать отдельный аккаунт и в таблице `users` назначить ему роль `admin` или `manager`. Затем войти и открыть `/admin` или нажать «Управление каталогом» в профиле.
- Добавить категорию, бренд и товар. Активный товар появится на `/katalog.html`. Чтобы удалить используемую категорию или бренд, сначала переназначить или удалить соответствующие товары.
- Нажатие на товар в каталоге открывает карточку. В форме товара можно добавить до 8 фото, выбрать обложку из сохранённых фото, заполнить характеристики парами «Название / Значение», добавить варианты упаковки и выбрать связанные товары.
- Поиск и фильтры идут отдельно. Рейтинг появится вместе с отзывами.

## Документация
Схема docs/SportFuel_DB_MySQL.drawio — проектная структура всего магазина. Миграции реализуют основу Laravel, пользователей и таблицы текущего каталога. Тип specs изменён с jsonb на json для MySQL. Структуры остальных функций будут уточняться перед их реализацией. ТЗ всё ещё содержит PostgreSQL/PHP8.5: принятые пользователем MySQL/PHP8.3 нужно отразить при согласованном обновлении ТЗ.
