# SportFuel Laravel
Laravel 13, PHP 8.3–8.5, MySQL/MariaDB. Выполнен первый шаг: регистрация. Остальные страницы пока статические.

## Локальный запуск на текущем ПК
1. В XAMPP Control Panel запустить MySQL. Apache для этого способа не нужен.
2. Открыть PowerShell в папке проекта.
3. Запустить `C:\php83\php.exe -c ..\php83-sportfuel.ini artisan serve --host=127.0.0.1 --port=8000`.
4. Открыть http://127.0.0.1:8000/reg-in.html.

База `sportfuel` и миграции уже подготовлены локально. `.env` и ключ не публикуются.

## На другом компьютере
Установить PHP >=8.3 с mbstring, openssl, curl, fileinfo, pdo_mysql и Composer. Выполнить `composer install`, скопировать `.env.example` в `.env`, указать свои параметры БД. Создать пустую БД sportfuel, выполнить `php artisan key:generate`, `php artisan migrate`, `php artisan serve`. Пароли БД и ключи у каждого окружения собственные.

## Проверка регистрации
Все поля обязательны. Логин — только латинские буквы, ФИО — кириллица, каждое до 30 символов; email до 30 символов, телефон — до 11 цифр. Пароль — от 10 до 72 символов: латинские буквы, цифры и спецсимволы. Повтор логина/email и несовпадающие пароли отклоняются. Пароль хранится как хеш bcrypt. Роль назначается сервером: user.

Контроллер: app/Http/Controllers/RegistrationController.php. Модель: app/Models/User.php. Маршруты: routes/web.php. Представление: resources/views/reg-in.blade.php. Таблица: users.

Проверены HTTP-отправка валидной формы, отклонение повторного логина/email (422), неверного логина и несовпадения паролей (422). Вход, выход и сброс пароля ещё не реализованы.

Структуры остальных функций будут уточняться перед их реализацией. ТЗ всё ещё содержит PostgreSQL/PHP8.5: принятые пользователем MySQL/PHP8.3 нужно отразить при согласованном обновлении ТЗ.
